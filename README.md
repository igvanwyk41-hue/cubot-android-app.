# CUBOT Android

An English-language Android app inspired by the official CUBOT website.

## Build
Requires JDK 17, Android SDK 35 and Gradle 8.9 or later.

```bash
gradle assembleDebug
```

APK output: `app/build/outputs/apk/debug/app-debug.apk`

The app is a native Android WebView shell with a locally bundled responsive interface. Product links and support references can be connected to live CUBOT pages as the app is expanded.
